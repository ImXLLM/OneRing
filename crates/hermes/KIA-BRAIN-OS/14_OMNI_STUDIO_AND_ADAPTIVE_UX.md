   (`Ctrl+K` / `Meta+K` و `/` از `index.js:L396–459`) و **درمانِ هر ۶ نقصِ قضاییِ

### ۳.۱ موتور A — `Fishkal` اقیانوسِ سرف و بلومِ هارمونیک (`index.html:L709–728, L1665–1750, L2172`)

- بافرِ براوان-نویزِ **۴ ثانیه‌ایِ لوپ‌شده**: `b0 = (b0 + 0.02 * white) / 1.02` با مقیاسِ `0.18`؛
- `BiquadFilterNode` لو-پسِ **۵۲۰Hz** با `LFO` سینوسیِ **۰٫۰۶Hz** و جاروبِ **±۲۲۰Hz**؛
- بلومِ پنتاتونیکِ رِ ماژور `[587.33, 880, 1174.66]` (`D5, A5, D6`) + آکوردِ امضای ۴-صدایی
  `[293.66, 440, 587.33, 880]` (`D4, A4, D5, A5`)؛
- `PRNG` قطعیِ **`xorshift32`**، نویزِ مقدارِ ۱-بعدیِ **۴-اکتاوی** (`fbm` با `f *= 2.03`)،
  `smoothstep` ارمایتِ مکعبی و `damp(a, b, l, dt)` مستقل از فریم با **لامبدا-متغیر**
  (`۲٫۳` درونِ پنجرهٔ گذارِ `0.42..0.63`، `۵٫۰` حالتِ عادی).

### ۳.۲ موتور B — `Portfolio Cosmos` ستاره‌باران و سینتِ دیلی-بازخورد (`cosmos.js:L6–60, L83–149, L216–269`)

- ستاره‌بارانِ 2D Canvas تعاملی: `DPR` سقفِ `2`، **۱۱۰ ستارهٔ موبایل / ۲۶۰ دسکتاپ**،
  گرادیان‌های سحابیِ شعاعی، میراییِ پارالاکسِ اشاره‌گرِ **۰٫۰۵**، نرم‌شوندگیِ مختصاتِ HUD
  با **۰٫۱۶** و **۷ گرهٔ تعاملیِ نقاطِ عطفِ مسیر**؛
- سینتِ دیلی-بازخورد: `DelayNode(0.22s)` + بازخوردِ `GainNode(0.25)` +
  `BiquadFilter(lowpass 1600Hz)` با هر ۵ تریگرِ SFX کانونی:
  - `ping(idx)` — سینوس → مثلثی، `220 + (idx % 7) * 40 Hz`، `0.12s`؛
  - `open()` — سینوسِ `180Hz → 520Hz` رامپِ نمایی، `0.28s`؛
  - `whoosh()` — نویزِ سفیدِ باند-پسِ `260Hz → 1200Hz`، `Q=2.2`، `0.32s`؛
  - `select()` — آکوردِ دو-گامیِ `[440, 660]` مثلثی، `0.07s` هر نُت؛
  - `milestone()` — آرپژِ سه-گامیِ `[330, 495, 660]` سینوسی، `0.09s` هر نُت.
