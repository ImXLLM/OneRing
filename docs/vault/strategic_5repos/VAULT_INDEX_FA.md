# فهرست گنجینهٔ استخراج‌شده از ۵ مخزن استراتژیک (`strategic-5repos-gems.zip`)

این آرشیو شامل کدهای اصلی، دیتابیس‌های طراحی، ضرایب ریاضی و آداپتورهای آمادهٔ تزریق به **`KIAN v2`** از ۵ مخزن زیر است:

1. **`01_x_algorithm_weights_and_formulas/`** — کدهای Rust موتور رتبه‌بندی `xai-org/x-algorithm` (`xai-value-model`, `home-mixer/params/param.rs`, `author_cold_start.rs`, `vm-ranker/scoring/dpp_model.rs`, `home-mixer/filters`, `user-cred-v2`) به همراه سند مهندسی وایرال شدن `@ImXforevr` و مشخصات رتبه‌بندی مارکت‌پلیس KIAN.
2. **`02_ui_ux_pro_max_skill_pack/`** — کل دیتابیس‌های طراحی `nextlevelbuilder/ui-ux-pro-max-skill` (۱۹۴ پالت رنگ، ۸۹ سبک، ۷۴ جفت فونت، ۱۴۱ قانون UX/دسترس‌پذیری، ۲۲ فایل استک و قوانین RTL فارسی/عربی)، اسکریپت جستجوی BM25 و ممیزی طراحی Playwright.
3. **`03_starnet_architecture_gems/`** — هستهٔ چندایجنتی `androoAGI/starnet` (`shared/specialties.js` با ۲۲ کلاس ایجنت، `sidecar/subagents.js` با واچ‌داگ عدم‌پیشرفت، `sidecar/taint.js`، `sidecar/compaction-fidelity.js`، `sidecar/capability/capGate.js`، ماژول‌های Rust در `src-tauri/src/` و ۵۶ مهارت `SKILL.md`).
4. **`04_gpt6_astra_prompts_and_patterns/`** — مستندات و الگوهای مهندسی از `MartinDelophy/awesome-gpt-6-astra` شامل `design-qa.md`، `PROMPT.md` / `DESIGN.md` / `VALIDATION.md` پروژه‌های مرجع (`thunderfall`, `orbital-garden`, `three-kingdoms`, `sunjing-puzzles`, `apex-club`).
5. **`05_agent_reach_zero_cost_connectors/`** — کل اتصال‌دهنده‌های اینترنتی رایگان `Panniantong/Agent-Reach` (`mcp.exa.ai`, `r.jina.ai`, `twitter.py`, `reddit.py`, `youtube.py`, `public_web.py`, گارد SSRF در `url.py`, و مهارت `SKILL_en.md`).
6. **`06_kian_v2_integration_adapters/`** — فایل‌های آمادهٔ تزریق به `KIAN v2`: ارتقای پرامپت KIAN Studio، رتبه‌بند Rust (`KIAN_X_ALGO_RANKER.rs`)، دستورالعمل اتصال رایگان `scout` و اسکریپت SQL جدول `"KbEntry"`.
